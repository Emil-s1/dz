ДОМАШНЕЕ ЗАДАНИЕ — МОДУЛЬ 5 «ПАРАЛЛЕЛЬНОЕ ПРОГРАММИРОВАНИЕ»

Среда: Visual Studio 2022
Тип: C# Windows Forms App (.NET Framework)
Целевая платформа: .NET Framework 4.8

КАК ОТКРЫТЬ
1. Распакуйте архив в отдельную папку.
2. Откройте файл ParallelProgramming_Module5.sln в Visual Studio 2022.
3. Если Visual Studio предложит установить .NET Framework 4.8 Developer Pack, согласитесь.
4. В меню «Сборка» выберите «Собрать решение».
5. Нажмите F5 для запуска.

ЧТО РЕАЛИЗОВАНО
Задания 1–3 (вкладка «Анализ текста»):
- Ввод текста и анализ в отдельной задаче Task.Run.
- Подсчёт предложений, символов, слов, вопросительных и восклицательных предложений.
- Выбор полей отчёта флажками.
- Вывод отчёта на экран или сохранение в TXT.
- Остановка через CancellationTokenSource и повторный запуск.

Задания 4–5 (вкладка «Файлы-дубликаты»):
- Выбор папок-источника и приёмника.
- Поиск дубликатов по SHA-256, включая вложенные папки (опция).
- Перемещение первого найденного экземпляра каждого уникального файла с сохранением структуры папок.
- Повторяющиеся файлы остаются в источнике.
- Формирование подробного журнала: перемещения, дубликаты, ошибки и итоговые счётчики.
- Остановка операции.

ВАЖНО
Перед запуском задания 4–5 сначала проверьте работу на тестовых копиях файлов.
Дубликатом считается файл с таким же SHA-256-хешем содержимого, даже если имя отличается.
При остановке уже выполненные перемещения не откатываются; отчёт об остановке отображается в приложении.
