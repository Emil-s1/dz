Домашнее задание — Модуль 1. Использование унаследованного кода
Visual Studio 2022 / C# / Microsoft .NET 8 / Windows Forms

В решении два независимых оконных приложения:

1. TargetApp — целевое окно с полями ФИО, группа и курс.
2. ApiController — второе приложение, управляющее TargetApp через Windows API.

ЗАДАНИЕ 1
В TargetApp нажмите «Задание 1 — показать информацию через MessageBox».
Данные из трёх полей будут показаны в отдельных системных MessageBox.
Перед демонстрацией замените значения полей на свои.

ЗАДАНИЕ 2
Запустите TargetApp. В ApiController оставьте исходный заголовок:
«Наследованный код — целевое окно».
Выберите действие:
- «Изменить заголовок» — отправляет WM_SETTEXT;
- «Закрыть окно» — отправляет WM_CLOSE;
- «Свернуть окно» — отправляет WM_SYSCOMMAND / SC_MINIMIZE.
Поиск выполняется функцией FindWindow.

ЗАДАНИЕ 3
В ApiController задайте количество сигналов и интервал.
Нажмите «Запустить сигналы». Используются импортированные функции
Beep из kernel32.dll и MessageBeep из user32.dll.
Для остановки нажмите «Остановить сигналы».

ЗАДАНИЕ 4
Запустите TargetApp и ApiController. В ApiController нажмите
«Переключить стиль кнопок (вкл./выкл.)».
Второе приложение перечисляет дочерние окна через EnumChildWindows,
находит элементы класса Button и меняет стиль WS_DISABLED через
GetWindowLongW / SetWindowLongW. Повторное нажатие возвращает кнопки
в исходное состояние.

КАК ЗАПУСТИТЬ
1. Распакуйте архив.
2. Откройте LegacyCodeModule1.sln в Visual Studio 2022.
3. Убедитесь, что установлена рабочая нагрузка «Разработка классических
   приложений .NET» и .NET 8 SDK.
4. Выберите нужный проект как запускаемый: TargetApp или ApiController.
5. Соберите решение и запустите оба приложения отдельно (для заданий 2 и 4).
   Можно сначала запустить TargetApp, затем ApiController.

ВАЖНО
Проект предназначен для Windows, так как использует Windows API и Windows Forms.
Для задания 4 кнопки TargetApp могут быть временно отключены. Если это произошло,
снова нажмите переключатель в ApiController, чтобы включить их.
