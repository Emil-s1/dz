# Модуль 4. Синхронизация — Visual Studio 2022

## Состав проекта
Одно приложение Windows Forms на C# / .NET 8 с четырьмя вкладками:

1. **События и файлы** — первый рабочий поток генерирует пары и сохраняет их; два других ждут `ManualResetEventSlim`, затем независимо записывают суммы и произведения.
2. **Один маршрут** — моделирование конечной остановки с автобусами одного маршрута №175.
3. **Разные маршруты** — пассажиры распределяются по маршрутам; автобус забирает только ожидающих пассажиров своего номера.
4. **Обычная остановка** — дополнительно моделируется выход части пассажиров из прибывшего автобуса перед посадкой новых.

Доступ к общим очередям пассажиров и состоянию автобусов защищён критической секцией `lock`. Потоки реализованы через `Task.Run` и асинхронные задержки; остановка моделирования выполняется через `CancellationTokenSource`.

## Запуск
1. Установите Visual Studio 2022 с workload **Разработка классических приложений .NET** и .NET 8 SDK.
2. Откройте `Module4Synchronization.sln`.
3. Выберите проект `Module4Synchronization` как запускаемый.
4. Нажмите **F5**.

Приложение предназначено для Windows (WinForms).
Результаты задания 1 сохраняются в папке `Task1Results` рядом с исполняемым файлом.
