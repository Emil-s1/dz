Домашнее задание — Модуль 3. Многопоточность и асинхронность, часть 2
Visual Studio 2022 / C# / Microsoft .NET 8 / Windows Forms

ПРОЕКТ
Один оконный проект с пятью вкладками — по одной на каждое задание.

ЗАДАНИЕ 1 — Танцующие прогресс-бары
Укажите количество полос (1–30) и нажмите «Старт».
Каждая полоса заполняется в отдельной задаче с разными случайными
приращениями, задержками и цветами. Кнопка «Остановить» отменяет работу.

ЗАДАНИЕ 2 — Конные скачки
Участвуют пять лошадей, каждая представлена ProgressBar.
Нажмите «Старт скачки». Скорость изменения прогресса случайная.
После финиша отображается таблица мест и времени.

ЗАДАНИЕ 3 — Числа Фибоначчи
Введите неотрицательную верхнюю границу (Int64) и нажмите кнопку.
Асинхронная задача вычисляет все числа Фибоначчи от 0 до границы,
показывает последовательность и количество чисел.

ЗАДАНИЕ 4 — Поиск слова в файле
Выберите файл, введите слово и нажмите «Найти в файле».
Программа асинхронно читает файл и показывает число вхождений.

ЗАДАНИЕ 5 — Поиск слова в директории
Выберите папку, введите слово и нажмите «Найти во всей директории».
Поиск рекурсивный — проверяются файлы во всех доступных подпапках.
Отчёт содержит название файла, полный путь и количество вхождений.
Кнопка «Отмена» останавливает поиск.

ОСОБЕННОСТИ ПОИСКА
- Поиск не учитывает регистр букв.
- Считаются неперекрывающиеся вхождения искомой строки.
- В отчёт по папке включаются только файлы, где найдено хотя бы одно совпадение.
- Недоступные или нечитаемые файлы пропускаются; их число указывается в отчёте.

КАК ЗАПУСТИТЬ
1. Распакуйте архив.
2. Откройте MultithreadingAsyncPart2.csproj в Visual Studio 2022.
3. Установите .NET 8 SDK и рабочую нагрузку «Разработка классических приложений .NET».
4. Соберите и запустите клавишей F5.

Проект предназначен для Windows, так как использует Windows Forms.
