Домашнее задание. Модуль 2 — Процессы
Visual Studio 2022 / C# / Microsoft .NET 8

СОСТАВ ПРОЕКТА
- ProcessManager — родительское оконное приложение Windows Forms.
- ChildProcess — отдельное консольное дочернее приложение.
Родитель запускает ChildProcess.exe и передаёт ему аргументы командной строки.

КАК ОТКРЫТЬ
1. Распакуйте архив.
2. В Visual Studio 2022 выберите «Открыть проект или решение».
3. Откройте ProcessManager.sln.
4. Убедитесь, что установлен компонент .NET 8 SDK и рабочая нагрузка
   «Разработка классических приложений .NET».
5. Соберите решение: Сборка -> Собрать решение.
6. Запустите проект ProcessManager клавишей F5.

ОПИСАНИЕ КНОПОК
Задание 1 — запустить и ждать:
  Запускает дочерний процесс, ожидает его завершения и показывает код 42.

Задание 2 — запустить и ждать:
  Запускает такой же 10-секундный дочерний процесс.
  Кнопка «Принудительно завершить» завершает активный дочерний процесс.
  Если дождаться завершения, родитель показывает код 42.

Задание 3:
  Передаёт дочернему процессу два числа и операцию (+, -, *, /).
  Пример: 7, +, 3. Дочерний процесс выводит аргументы и результат 10.

Задание 4:
  Передаёт дочернему процессу путь к файлу и слово.
  Дочерний процесс выводит количество вхождений искомой строки.
  Поиск не учитывает регистр и считает вхождения подстроки.

ПРИМЕЧАНИЕ
Проект использует .NET 8. Для запуска нужен Windows, поскольку интерфейс
родительского приложения создан на Windows Forms.
